Programa desarrollado en C# que utiliza:

-Variables de tipo string, int, decimal y bool.
-Console.WriteLine() para mostrar información en pantalla.
-Console.ReadLine() para recibir datos del usuario.
-Métodos para organizar las diferentes operaciones del programa.
-do while para repetir el menú principal.
-switch para seleccionar las opciones del sistema.
-if para validar condiciones.
-foreach para recorrer y mostrar las funciones registradas.
-TryParse() para validar y convertir los datos ingresados.
-try catch para controlar errores.
-List<Funcion> para almacenar y mostrar las funciones.
-FuncionRepositorio para realizar operaciones con la base de datos SQL Server.

-Abrir el proyecto en Visual Studio Community.
-Presionar F5 para ejecutar el programa.
